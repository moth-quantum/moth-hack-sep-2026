# Brand fonts (licensed, not in the repo)

The identity deck (Moth_Hack-Identity v1) is set in **Riforma LL** (Lineto) and the key
visual in a matching mono (**Riforma Mono**). Both are commercial. Drop the licensed
woff2 files here with exactly these names and the page picks them up with no code change:

| File | Used for |
|---|---|
| `RiformaLL-Regular.woff2` | body copy |
| `RiformaLL-Medium.woff2` | title, subtitle, buttons |
| `RiformaLL-Bold.woff2` | reserved |
| `RiformaMono-Regular.woff2` | kicker, dateline, schedule labels, the Moth_Hack grid |

Until they exist the stacks fall back to Helvetica / Arial and the system monospace.
Boris Meister holds the licence. Do not commit the files to a public repo unless the
licence allows web embedding for this domain.
